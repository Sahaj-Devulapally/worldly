# Worldly

Learn all 197 countries, their flags and capital cities. It's a plain web app (no build step) that can be installed on a phone and works offline.

## Run it locally
```bash
python3 -m http.server 8765
```
Then open http://localhost:8765.

## Put it online (free)
Upload the contents of this folder to any static host:
- **GitHub Pages:** push the folder to a repo, then turn on Pages under Settings → Pages.
- **Netlify:** drag the folder onto https://app.netlify.com/drop.

## Install on your phone
Open the site URL on your phone.
- **iPhone (Safari):** tap Share, then Add to Home Screen.
- **Android (Chrome):** tap ⋮, then Install app.

## Sync between devices
Progress syncs through Supabase. The project URL and public (publishable) key live in `config.js`. The table and its security rules are in `tools/supabase-setup.sql`. Sign in under Settings → Sync with the same email and password on each device.

## Updating
After you change any file, bump `VERSION` in `sw.js`. Otherwise installed copies keep serving the old cached version.

## Files
- `index.html`, `styles.css`, `app.js`: the app
- `data.js`: countries, capitals and regions (generated by `tools/build.py`)
- `map.js`, `mapquiz.js`: map outlines (Natural Earth, public domain; generated by `tools/build_map.py`) and the map quiz
- `flags/`: SVG flags from flag-icons (MIT)
- `sync.js`, `config.js`: cloud sync (Supabase)
- `facts/`: "Did you know?" facts, three per country
- `sw.js`, `manifest.webmanifest`, `icons/`: what makes it installable and work offline

Country data comes from world-countries (ODbL), with fixes such as Astana, Ulaanbaatar and the multiple capitals of Bolivia and South Africa.
